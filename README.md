# Retro Strike

## Project Description

**Retro Strike** is a simple 2D arcade shooter where the player controls a character or vehicle, moves left and right, shoots incoming enemies, avoids collisions, and tries to survive while earning points.

The project aims to recreate the simple and enjoyable feeling of classic mobile shooting games while applying fundamental computer graphics and game-development concepts.

The focus will be on building a **small, complete, and visually polished game** rather than a large or complex project.



## Project Goals

The main goals are to:

- Create a playable 2D arcade shooting game
- Implement smooth player movement and shooting
- Add enemies and basic enemy movement
- Implement collision detection
- Add score and player lives
- Introduce increasing difficulty
- Add simple sprite animations
- Create explosion and hit effects
- Add a scrolling or parallax background
- Produce a polished retro-style final version

### Basic Gameplay

**Start → Move & Shoot → Destroy Enemies → Survive → Earn Score → Game Over → Restart**



## Computer Graphics Focus

The project will explore several 2D computer graphics concepts:

- **Sprite rendering**
- **Sprite animation**
- **2D transformations and movement**
- **Collision detection**
- **Scrolling backgrounds**
- **Parallax effects**
- **Particle effects**
- **Real-time visual feedback**

These features will be developed gradually as the project progresses.

## Foreseeable Difficulties

During development, some expected challenges are:

- Making player movement smooth and responsive
- Managing collisions between players, enemies, and projectiles
- Creating simple but interesting enemy movement
- Balancing enemy speed, number, and difficulty
- Creating a consistent retro visual style
- Managing animations and visual effects
- Keeping the overall project scope manageable

The main priority will be to complete the **core gameplay first**. Additional features will only be added after the essential functionality is working.



# Milestone 1 — Basic Game Setup

## Goal

Create the initial game environment and implement basic player movement.

## Tasks

1. Create the Godot project
2. Create the main game scene
3. Add a simple background
4. Add the player
5. Implement left and right movement
6. Keep the player inside the game area
7. Create the GitHub repository

## Expected Result

At the end of Milestone 1, the project should launch successfully and display a basic 2D game scene.

The player should be visible and able to move smoothly left and right while remaining inside the playable area.
